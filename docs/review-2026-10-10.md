## Баги

### 1. OTP: опечатка в регулярке — `/D/g` вместо `/\D/g`

- [x] `src/components/ui/otp/input.tsx:103`
- Суть: `input.value.replace(/D/g, "")` вырезает букву «D», а не нецифры.
  Все остальные места файла используют `/\D/g`.
- Сценарий: `sync()` — единственный путь, которым программная запись
  `input.value` (reset формы, `setValue` react-hook-form) попадает в слой
  ячеек. Значение `"12-34"` рисует пять ячеек, одна из них с дефисом; индексы
  каретки считаются по неочищенной строке. Клавиатура и вставка не страдают,
  потому что `applyChange` чистит значение раньше.
- Правка: `/\D/g`. Тест: записать `ref.current.value = "12-34"` и проверить,
  что ячеек четыре.

### 2. File Upload: `accept="*/*"` отвергает все файлы

- [x] `src/components/ui/file-upload/accept.ts:47-50`
- Суть: `matchesMime("image/png", "*/*")` → `type.startsWith("*/")` → false;
  голая `"*"` → `type === "*"` → false. Браузер трактует `*/*` как «любой».
- Сценарий: `<FileUploadDropzone accept="*/*">` — всё уходит в
  `onFilesRejected`, в `onFilesSelected` ничего.
- Правка: в `matchesMime` первым делом `if (token === "*" || token === "*/*")
  return true`.

### 3. File Upload: у `<input type="file">` нет доступного имени

- [x] `src/components/ui/file-upload/dropzone.tsx:192-209`
- Суть: input получает `id={inputId}` из `useId()`, но на него никто не
  ссылается — ни `<label htmlFor>`, ни `aria-labelledby` на текст «Перетащите
  или загрузите файлы». `inputId` — мёртвый код.
- Сценарий: скринридер объявляет безымянный file-контрол; подпись и
  `subtitle` (форматы, лимиты) не читаются.
- Правка: дать `id` текстовому узлу подписи и подзаголовку, повесить на
  input `aria-labelledby` / `aria-describedby`.

### 4. Sortable: любой нативный drag внутри строки запускает перестановку

- [x] `src/components/ui/sortable/use-sortable.ts:339-350`
- Суть: `onDragStart` проверяет только `movable`, но не `armedId === id`.
  `draggable` у невзведённой строки false, но `dragstart` от draggable-потомка
  (выделенный текст, `<a href>`, `<img>`) всплывает до строки, обработчик
  перезаписывает `dataTransfer`, прячет фантом и ставит `dragId`; дальше
  `onDragOver`/`onDrop` списка переставляют.
- Сценарий: в `table/column-settings.tsx` (там текст выделяемый, в отличие от
  избранного с `select-none`) выделить подпись колонки мышью, протянуть вниз
  на две строки, отпустить — колонка переставлена, вопреки правилу «захват
  по иконке».
- Правка: `if (!movable || armedId !== id) return` в начале `onDragStart`.

### 5. Tab Headings: группа выпадает из Tab-порядка при disabled активной

- [x] `src/components/ui/tab-headings/tab-headings.tsx:112`
- Суть: `tabIndex={active ? 0 : -1}`; `useItemsValue` подставляет другое

- Сценарий: `items=[{value:"a",disabled:true},{value:"b"}]`, `value="a"` —
